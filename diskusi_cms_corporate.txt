====================================================
PERBANDINGAN AWAL (dari claude.ai)
====================================================

Laravel + Vue.js VS Next.js
- Next.js lebih unggul untuk SEO karena SSR/SSG built-in
- Vue.js biasa (SPA) = SEO buruk karena render di client
- Kalau tetap Vue, minimal pakai Nuxt.js

SSR vs SSG vs CSR
- SSR  : Render tiap ada request (cocok untuk konten dinamis)
- SSG  : Render sekali saat build/deploy (cocok untuk company profile)
- CSR  : Render di browser (SEO buruk, hindari untuk public page)

====================================================
ANALYTICS DASHBOARD (CUSTOM TRACKER)
====================================================

Keputusan:
  - Pakai custom tracker (self-hosted, data di DB sendiri)
  - TIDAK pakai GA4 (untuk saat ini)
  - Unique visitor tracking via COOKIE
  - Referrer tracking PERLU
  - Device tracking → nanti

Tabel database:
  page_views   → raw data setiap kunjungan
  daily_stats  → agregasi harian (agar query dashboard cepat)

Tiga lapis filter bot:
  1. Client-side tracking → bot tanpa JS otomatis tidak ter-track
  2. User-Agent blacklist → filter di API endpoint
     (googlebot, bingbot, scrapy, curl, selenium, dll.)
  3. Deduplication via sessionStorage → refresh tidak tambah views

Alur tracking:
  Pengunjung buka halaman
      ↓
  Cek sessionStorage (sudah di-track session ini?)
      YA  → stop
      TIDAK → lanjut
      ↓
  Kirim ke /api/analytics/track via sendBeacon
      ↓
  API cek User-Agent (bot? → skip)
      ↓
  Simpan ke page_views + update daily_stats

Tampilan dashboard:
  - Cards: pengunjung hari ini, page views, artikel terpopuler, inquiry baru
  - Grafik: tren kunjungan 7/30/90 hari
  - Tabel: top halaman & artikel by views
  - Sumber traffic (referrer breakdown)
