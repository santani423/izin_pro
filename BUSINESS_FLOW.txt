DESKRIPSI BISNIS
----------------
IzinPro adalah layanan jasa perizinan bisnis yang membantu
pengusaha dalam mengurus dokumen legal perusahaan, mulai dari
pendirian PT/CV, NIB/OSS, PKP & NPWP, hingga izin usaha khusus.

Website ini berfungsi sebagai:
  1. Company profile digital yang menarik (konversi prospek)
  2. Kanal komunikasi utama via WhatsApp & form kontak
  3. Platform publikasi artikel/blog (SEO + edukasi)
  4. Admin CMS untuk mengelola seluruh konten website

====================================================
ALUR KONTEN ADMIN — PENGELOLA WEBSITE
====================================================

SIAPA YANG PAKAI ADMIN PANEL:
  - Super Admin  → akses penuh semua fitur
  - Admin        → kelola konten, lihat inquiry
  - Editor       → hanya kelola blog & media
  - Viewer       → hanya baca dashboard (read-only)

ALUR PENGELOLAAN KONTEN BLOG:

  Admin buat artikel baru
      ↓
  Isi judul, konten (rich text), gambar cover, kategori, tag
      ↓
  Atur status: Draft → Review → Published
      ↓
  Artikel tayang di /blog/[slug] (auto SEO metadata)
      ↓
  Sitemap.xml update otomatis (Google index)

ALUR PENGELOLAAN MEDIA:

  Upload gambar (drag & drop di /admin/media)
      ↓
  Sharp.js otomatis:
    - Convert ke WebP
    - Generate 3 ukuran: thumbnail (150px), medium (600px), large (1200px)
  Simpan path di database, file di folder /public/uploads/
      ↓
  Gambar siap digunakan di editor konten

ALUR PENGELOLAAN INQUIRY (Form Kontak):

  Pengunjung submit form di /kontak
      ↓
  Data tersimpan di tabel contact_submissions
      ↓
  Email notifikasi dikirim ke admin
      ↓
  Admin buka /admin/dashboard → lihat inquiry baru
      ↓
  Admin tindak lanjut via WhatsApp / email
      ↓
  Status inquiry update: Baru → Diproses → Selesai

ALUR PENGELOLAAN LAYANAN:

  Admin buka /admin/layanan
      ↓
  Tambah / edit / hapus layanan
      ↓
  Toggle aktif/nonaktif per layanan
      ↓
  Layanan aktif otomatis tampil di website publik

====================================================
ALUR DATA — WEBSITE PUBLIK
====================================================

HOMEPAGE LOAD:
  Browser request /
      ↓
  Next.js SSG: HTML sudah di-generate saat build
      ↓
  Served dari CDN / cache langsung (super cepat)
      ↓
  JavaScript hydrate untuk interaktivitas (counter, slider, FAQ)

HALAMAN LAYANAN DETAIL (/layanan/[slug]):
  Browser request /layanan/pt-baru
      ↓
  Next.js SSG: halaman sudah di-build (generateStaticParams)
      ↓
  HTML statis di-serve (Google bisa index konten ini)

HALAMAN BLOG (/blog/[slug]):
  Browser request /blog/tips-memilih-jasa-pengurusan-pt
      ↓
  Next.js SSG: artikel sudah di-build
      ↓
  HTML statis di-serve (SEO optimal)

FORM KONTAK (fase backend):
  User isi form + submit
      ↓
  Next.js Server Action POST /api/contact
      ↓
  Validasi data (Zod schema)
      ↓
  Simpan ke tabel contact_submissions (Prisma → MariaDB)
      ↓
  Kirim email notifikasi ke admin
      ↓
  Response: sukses / gagal dikembalikan ke user

====================================================
ALUR ANALYTICS (fase backend)
====================================================

Setiap halaman publik dibuka:
  Halaman render di browser
      ↓
  Cek sessionStorage (sudah di-track session ini?)
    YA  → stop (tidak tambah view ganda per session)
    TIDAK → lanjut
      ↓
  Kirim beacon ke /api/analytics/track
    Payload: { url, referrer, user_agent, timestamp }
      ↓
  API endpoint cek User-Agent (bot/crawler? → skip)
      ↓
  Cek cookie unique visitor (baru vs returning)
      ↓
  INSERT ke tabel page_views
      ↓
  UPDATE tabel daily_stats (agregasi harian)

Dashboard analytics tampilkan:
  - Card: pengunjung hari ini, page views, artikel terpopuler, inquiry baru
  - Chart: tren kunjungan 7 / 30 / 90 hari
  - Tabel: top halaman by views
  - Sumber traffic (referrer breakdown)
