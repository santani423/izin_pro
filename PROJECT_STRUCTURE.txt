OVERVIEW

untuk IzinPro, dibangun dengan Next.js 16.x + TypeScript + Tailwind CSS v4.

dengan backend (Prisma + MariaDB + Better Auth) di fase berikutnya.

====================================================
KONVENSI CODING
====================================================

PENAMAAN FILE:
  - Komponen React       → PascalCase.tsx (contoh: HeroSection.tsx)
  - Halaman Next.js      → lowercase/page.tsx (konvensi App Router)
  - Utility / lib        → camelCase.ts (contoh: constants.ts, utils.ts)

KOMENTAR:
  - Komentar bagian file  → /* ─── Nama Bagian ─── */ (Bahasa Indonesia)
  - Inline comment        → Bahasa Indonesia, singkat, hanya jika perlu
  - Variabel & fungsi     → Bahasa Inggris

"USE CLIENT" vs SERVER COMPONENT:
  - Default: Server Component (tidak perlu 'use client')
  - Tambahkan 'use client' HANYA jika komponen:
    - Menggunakan useState / useEffect / useRef
    - Menggunakan event handler (onClick, onChange, dll.)
    - Menggunakan hooks lainnya

CSS / TAILWIND:
  - Gunakan OKLCH untuk warna: bg-primary, text-brand-700, dll.
  - Hindari hardcode hex color — gunakan CSS variable via Tailwind
  - Responsive prefix: sm: (640px) md: (768px) lg: (1024px) xl: (1280px)
  - Dark mode siap: dark: prefix tersedia (next-themes sudah terinstall)

PANDUAN INTEGRASI BACKEND (FASE BERIKUTNYA)
====================================================

LANGKAH 1 — Setup Prisma + MariaDB
  npm install prisma @prisma/client
  npx prisma init
  → Edit prisma/schema.prisma (lihat tabel di diskusi_cms_corporate.txt)
  → Ubah DATABASE_URL di .env ke koneksi MariaDB

LANGKAH 2 — Ganti mock data dengan data dari DB
  Contoh di src/app/(public)/blog/page.tsx:

  SEBELUM (mock):
    import { BLOG_POSTS } from "@/lib/constants"
    const posts = BLOG_POSTS

  SESUDAH (database):
    import { db } from "@/lib/db"    // Prisma client
    const posts = await db.post.findMany({ where: { status: "published" } })

  Halaman akan otomatis jadi Server Component yang fetch dari DB.

LANGKAH 3 — Setup Authentication (Better Auth)
  npm install better-auth
  → Buat src/lib/auth.ts
  → Tambahkan middleware.ts di root untuk proteksi route /admin/*
  → Ganti halaman /admin/* yang saat ini tidak ada auth-nya

LANGKAH 4 — Server Actions untuk Admin CRUD
  Contoh tambah artikel:
    // src/app/admin/blog/actions.ts
    "use server"
    import { db } from "@/lib/db"
    import { revalidatePath } from "next/cache"

    export async function createPost(data: PostFormData) {
      await db.post.create({ data })
      revalidatePath("/blog")
      revalidatePath("/admin/blog")
    }

LANGKAH 5 — Media Upload
  npm install sharp multer
  → Buat src/app/api/upload/route.ts
  → Generate 3 ukuran: thumbnail (150px), medium (600px), large (1200px)
  → Simpan ke /public/uploads/ + INSERT ke tabel media di DB

LANGKAH 6 — Contact Form Backend
  Saat ini form ada langsung di src/app/(public)/kontak/page.tsx,
  handleSubmit() simulasi submit (setTimeout), belum kirim ke mana pun.
  Untuk koneksikan ke backend:
  → Buat src/app/api/contact/route.ts
  → Ganti handleSubmit() di kontak/page.tsx untuk POST ke /api/contact
  → Tambahkan email notifikasi (nodemailer / Resend)
